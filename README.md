# Lanthera Health — Demo Website

> **Notice:** Fictional frontend-only demo website for a multi-speciality hospital network.

## Quick Start

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev` — Launch Vite dev server
- `npm run build` — Typecheck and production build
- `npm run typecheck` — TypeScript strict type checking
- `npm run lint` — ESLint code quality checks
- `npm run test` — Run Vitest unit tests
- `npm run test:e2e` — Playwright end-to-end route tests
- `npm run check:i18n` — Verify EN/HI key parity
